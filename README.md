# ClipXS

English | [日本語](README.ja.md)

A lightweight clipboard-history app for macOS, inspired by the Windows `Win + V` workflow. Press `Option + Command + V` to search recent clipboard items and paste into the current app.

## Features

- Clipboard history for text, links, images, and files, with rich text preserved
- Search, type filters, source-app icons, and a preview pane with selectable text and scrolling image previews
- Pinned items that stay at the top and are exempt from history limits and automatic deletion
- Plain-text paste, text transformations, and editing before pasting
- Multiple selection: combine text with newlines or paste selected image/file attachments together
- Paste queue: paste entries in order with `Command + V`, `Control + V`, or `Shift` plus the history hotkey
- On-device image text recognition (OCR), including Japanese; recognized text can be searched, copied, and pasted
- Configurable hotkey, history limit (10–1000 items, default 100), retention, excluded apps, and per-app plain-text paste rules
- Password-manager clipboard exclusion using ConcealedType, TransientType, and AutoGeneratedType markers
- Menu-bar app with optional launch at login and no Dock icon
- English and Japanese interface following the macOS language

## Requirements

- macOS 13 or later
- Xcode 15 or later to build
- [XcodeGen](https://github.com/yonaskolb/XcodeGen) to regenerate the project from `project.yml` (optional)

## First-time setup

1. Launch `ClipXS.app`.
2. Enable ClipXS under **System Settings > Privacy & Security > Accessibility** to allow automatic paste and queue shortcuts.
3. Optionally enable **Launch at Login** in Settings, available from the menu-bar icon's right-click menu.
4. Copy something, press `Option + Command + V`, and choose an item.

## Controls

| Action | Result |
|---|---|
| `Option + Command + V` | Open or close history (configurable) |
| Typing | Search history, including recognized image text |
| `↑` / `↓` | Move through items |
| `Return` | Paste the selected item |
| `Shift + Return` | Paste as plain text |
| `Command + 1`–`9` | Paste the corresponding visible item |
| `Command + click` | Toggle multiple selection |
| `Command + Return` | Add the selection to the paste queue |
| `Command + V` / `Control + V` | Paste the next queued item in the destination app |
| `Shift + Option + Command + V` | Paste the next queued item (default queue hotkey) |
| `Command + E` | Edit a text item; `Command + Return` saves, `Esc` cancels |
| `Command + Delete` | Delete the selected item |
| `Command + P` | Pin or unpin the selected item |
| `Esc` | Clear search, then multiple selection, then close history |
| Right-click an item | Paste, transform, copy, queue, edit, pin, or delete |

Selected images and files can be combined into one attachment paste or queue item. Text and attachment selections cannot be combined. The queue hotkey adds `Shift` to the history hotkey; it is unavailable if that hotkey already includes `Shift`.

Clipboard history is stored locally under `~/Library/Application Support/ClipXS/`. The default limit is 100 unpinned items. Pinned items are exempt from the limit and retention policy.

## Settings

Right-click the menu-bar icon and choose **Settings…** to configure the hotkey, history limit, retention (unlimited, 24 hours, one week, or one month), OCR, excluded apps, per-app plain-text paste rules, launch at login, or clear history.

## Build and test

```bash
git clone https://github.com/porarrirr/clipxs.git
cd clipxs
# Optional: regenerate the checked-in Xcode project
xcodegen generate
xcodebuild -scheme ClipXS -configuration Release -derivedDataPath build build
open build/Build/Products/Release/ClipXS.app
```

Debug build:

```bash
xcodebuild -scheme ClipXS -configuration Debug -derivedDataPath build build
```

Tests:

```bash
xcodebuild -scheme ClipXS -derivedDataPath build test
```
