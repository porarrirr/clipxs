# ClipXS

[English](README.md) | 日本語

Windows の **Win+V** 相当のクリップボード履歴アプリ for macOS。

## リポジトリ

```bash
git clone https://github.com/porarrirr/clipxs.git
cd clipxs
```

`project.yml` から Xcode プロジェクトを再生成する場合（[XcodeGen](https://github.com/yonaskolb/XcodeGen) が必要）:

```bash
xcodegen generate
```

## 主な機能

- **履歴パネル**: `Option + Command + V`(変更可能)で Raycast 風パネルを表示。検索バー・タイプ別フィルタ・大きなプレビューペイン付き
- **対応種別**: 文章(リッチテキスト保持)・リンク・画像・ファイル
- **検索 / フィルタ**: インクリメンタル検索(日本語対応)+ すべて / 文章 / リンク / 画像 / ファイルのフィルタ
- **コピー元アプリの記録**: どのアプリでコピーしたかをアイコンで表示
- **ピン留め**: ピン留めした項目は常に先頭に表示され、履歴上限・自動削除の対象から除外
- **プレーンテキスト貼り付け**: リッチテキストの書式を外して貼り付け(`⇧↩`)
- **即貼り付け**: `⌘1`〜`⌘9` で表示中の n 番目を即貼り付け
- **ペーストキュー**: 複数項目をキューに積み、貼り付け先で `⌘V` / `Ctrl+V` または `⇧` + ホットキー(既定 `⇧⌥⌘V`)で1件ずつ順番に貼り付け。まとめて選択した画像・ファイルは1回で全件貼り付け（アクセシビリティの許可が必要）
- **変換して貼り付け**: 大文字 / 小文字 / 改行削除 / 空白整理 / URL デコードを適用してプレーン貼り付け
- **結合貼り付け**: `⌘クリック` で複数選択した文章を改行区切りで、画像・ファイルは添付として 1 回に貼り付け（文章と添付の混在選択は結合不可）
- **画像内テキスト認識(OCR)**: コピーした画像内の文字を Vision で認識(日本語対応・オンデバイス)。検索対象になり、テキストとして貼り付け / コピーも可能
- **履歴の編集**: テキスト項目をパネル内で編集してから貼り付け(`⌘E`)
- **アプリ別プレーン貼り付けルール**: 指定アプリへは常にプレーンテキストで貼り付け(ターミナル等)
- **保存期間の自動削除**: 24時間 / 1週間 / 1ヶ月経過した履歴を自動削除(既定は無制限)
- **ライブ更新**: パネル表示中に他アプリでコピーしても一覧が即時反映
- **パスワード除外**: パスワードマネージャ等が付与する `org.nspasteboard.ConcealedType` / `TransientType` / `AutoGeneratedType` のコピーは記録しない
- **設定画面**: ホットキー変更・履歴上限(10〜1000 件)・保存期間・OCR・除外アプリ・プレーン貼り付けアプリ・ログイン時起動・履歴消去
- **常駐**: メニューバー(Dock に表示されません)

## 必要環境

- macOS 13 以降
- Xcode 15 以降(ビルド時)

## ビルド

```bash
cd /path/to/clipxs
xcodebuild -scheme ClipXS -configuration Release -derivedDataPath build build
open build/Build/Products/Release/ClipXS.app
```

Debug ビルド:

```bash
xcodebuild -scheme ClipXS -configuration Debug -derivedDataPath build build
open build/Build/Products/Debug/ClipXS.app
```

テスト:

```bash
xcodebuild -scheme ClipXS -derivedDataPath build test
```

履歴操作の性能計測結果と再現手順: [Benchmarks/README.md](Benchmarks/README.md)

## 初回セットアップ

1. `ClipXS.app` を起動する(メニューバーにクリップボードアイコンが表示されます)
2. **システム設定 → プライバシーとセキュリティ → アクセシビリティ** で **ClipXS** をオンにする
   (履歴から選択した内容を自動で `⌘V` 貼り付けするために必要です)
3. (任意)メニューバー右クリック → **設定…** → **ログイン時に起動** をオンにする
   初回は **システム設定 → 一般 → ログイン項目** で ClipXS を許可する必要がある場合があります
4. 任意のテキストをコピーし、貼り付け先で `Option + Command + V` を押す
5. 履歴から項目を選択(クリックまたは `↑` `↓` + `Return`)

## 使い方

| 操作 | 説明 |
|------|------|
| `Option + Command + V` | 履歴パネルを開く / 閉じる(設定で変更可能) |
| `⌘V` / `Ctrl+V` | キューがある間、貼り付け先で次の1件を貼り付け |
| `Shift + Option + Command + V` | ペーストキューの次の項目を貼り付け(ホットキー + `⇧`) |
| 文字入力 | 履歴をインクリメンタル検索(画像は OCR テキストも対象) |
| `↑` / `↓` | 項目を移動 |
| `Return` | 選択して貼り付け |
| `Shift + Return` | プレーンテキストとして貼り付け |
| `⌘1` 〜 `⌘9` | 表示中の n 番目を即貼り付け |
| `⌘クリック` | 複数選択(結合貼り付け・キュー追加の対象) |
| `⌘Return` | 選択中の項目(複数選択があればその全件)をペーストキューに追加 |
| `⌘E` | テキスト項目を編集(`⌘↩` 保存 / `Esc` キャンセル) |
| `⌘Delete` | 選択項目を削除 |
| `⌘P` | 選択項目をピン留め / 解除 |
| `Esc` | 検索クリア → 複数選択解除 → パネルを閉じる |
| 右クリック | 貼り付け / プレーン貼り付け / 変換して貼り付け / キューに追加 / 編集 / コピー / ピン留め / 削除など |
| メニューバーアイコン | クリックで履歴を開く。右クリックでメニュー(設定…など) |

履歴は既定で最大 **100 件**(設定で 10〜1000 件に変更可)まで `~/Library/Application Support/ClipXS/` に保存されます。ピン留めした項目は件数上限の対象外です。

## 設定

メニューバーアイコン右クリック → **設定…** から:

- **ホットキー**: 履歴パネルを開くショートカットを録画形式で変更(競合時は自動で元に戻ります)
- **履歴の最大件数**: 10〜1000 件
- **履歴の自動削除**: しない / 24時間後 / 1週間後 / 1ヶ月後(ピン留めは対象外)
- **画像内テキスト認識(OCR)**: オン / オフ切り替え
- **除外アプリ**: 指定したアプリでのコピーを記録しない(アプリ選択またはバンドル ID 入力)
- **プレーンテキスト貼り付けアプリ**: 指定したアプリへは常にプレーンテキストで貼り付け
- **ログイン時に起動**
- **履歴の消去**
